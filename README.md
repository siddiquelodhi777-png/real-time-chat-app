# 💬 ChatFlow — Real-Time Chat App

A modern, professional and responsive **frontend-only real-time chat interface** built using:

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- localStorage

The application simulates a real-time chat experience without requiring a backend.

---

# 🚀 Features

## Core Task Features

### 1. Chat Input

Users can type messages using the message input field.

### 2. Send Button

Messages can be sent using the Send button.

### 3. Instant Messages

Sent messages immediately appear in the chat area.

### 4. Sent and Received Messages

Sent and received messages have different UI styles.

### 5. localStorage

Messages are saved using browser localStorage.

Refreshing the page does not remove the chat history.

### 6. Responsive Design

The application works on:

- Desktop
- Laptop
- Tablet
- Mobile

### 7. Smooth Animations

The project includes:

- Message animations
- Typing animation
- Button hover animations
- Modal animations
- Theme transitions
- Avatar animation
- Online indicator animation
